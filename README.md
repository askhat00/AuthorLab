# АвторLab

Простой школьный веб-проект по теме «Человек или искусственный интеллект? Лингвистический эксперимент по распознаванию авторства русскоязычных стихотворений».

Проект исследования: Серік Мөлдір Ерболқызы, 10 класс. Руководитель: Макенова Гульжан Танатаровна. Школа имени Какимбека Салыкова, район Шал акына.

## Запустить за минуту

1. Распакуйте архив.
2. Откройте `index.html` в Chrome, Edge или Firefox.
3. Выберите группу, подтвердите согласие и начните эксперимент.


## Что работает

- Анонимный случайный код без имени и контактов.
- Выбор одной из трёх групп, предусмотренных исследованием.
- Основное исследование и отдельно технический пилот.
- Первый этап: 8 фрагментов, 4 человеческих и 4 машинных.
- Случайный порядок внутри каждого этапа, сохраняющийся при возобновлении.
- Обязательный выбор источника, уверенности 1–5 и главной причины.
- Отдельная отметка узнавания строки или автора.
- Памятка между этапами, без раскрытия правильных ответов.
- Второй этап: 8 новых фрагментов с тем же балансом.
- Личная точность до и после памятки, изменение в процентных пунктах.
- Восстановление незавершённого теста через кнопку на главной.
- Панель исследователя: средние, медиана и диапазон изменения, группы, причины, уверенность верных и ошибочных ответов, точность без узнавания.
- CSV сводки и CSV отдельных ответов: 16 строк на завершённого участника.
- JSON для резервной копии и объединения результатов с разных устройств.
- Проверка структуры и версии импортируемого файла, защита от повторного кода.
- Ключ с авторами открывается отдельно после подтверждения окончания сбора.
- Адаптация интерфейса для телефона, управление с клавиатуры.
